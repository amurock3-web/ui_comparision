    Help

    Verdicts

    PASS
    Every check is within tolerance. Minor-only failures still pass, with warnings.
    REVIEW
    Borderline, or the system is unsure (low detection confidence, ambiguous match). A person should look. Any REVIEW and no FAIL gives REVIEW.
    FAIL
    Clearly outside tolerance. Any Critical or Major failure fails the screen.

    What is checked

    Geometry and chrome only. Poster artwork, titles inside rails and the status bar are live content and never compared.

    A. Screen-level
    Orientation and blank or broken screens; a Critical failure here skips B to G.
    B. Layout & structure
    Missing or extra elements, section and tab order, alignment, spacing, overlap, clipping, cards per rail.
    C. Position & size
    Each matched element's shift, size change, aspect distortion and card type, as a percentage of the screen.
    D. Color
    Brand, background, text, selected-state and badge colours (ΔE2000 in Lab), scrims and contrast.
    E. Text & typography
    Static UI labels only (tabs, buttons, section titles): wording, truncation, case, script, font size, overflow, alignment.
    F. Images, icons & logo
    Logo and icons match (crop similarity), broken or stretched images; never poster artwork.
    G. Interaction state
    Same tab selected, focus ring on the same element, same enabled/disabled look.

    Results page

    Click an issue to highlight its boxes on both screenshots; hover a box for its class and text. Each issue can be accepted (written to the accepted-differences file, so the next run reports it as PASS), turned into an ignore region (a NONE region in the screen's rules file) or marked as a bug (review.json in the run). Every change says which file it wrote and can be undone. Re-check redoes matching and the report from the saved OCR in a few seconds and saves report_N.json / .html beside the original.

    Where runs are stored

    Each comparison is kept in output/app/<YYYYMMDD_HHMMSS>/: the two screenshots, production_fused.json and client_fused.json, and report.json, .html, .png and .pdf. The History page lists them.

    Starting the app

    Double-click UI Compare.bat in the project folder, or run python -m src.app (add --port 8800 or --no-browser if needed). It listens on 127.0.0.1 only. Heavy jobs (comparisons, adding a baseline, batch items) run one at a time; the others wait in a queue and show "queued (#n)".
